Priest click-casting: instance checklist

Enable logging, mark a failed click, then identify what restores casting.

EUI Click Trace is a temporary addon written by Codex for this investigation. It is separate from official EllesmereUI. It records diagnostics without changing your spell bindings.

A. EnableB. Mark a problemC. Recovery testsD. Settings testsE. Save and report

Keep the group alive first. Do not delay a needed heal to run a test. Use right-click Flash Heal consistently, stand still, keep the tank in range, and allow the cast/global cooldown to finish between attempts.

A. Enable before entering the instance

The addon files are already installed on this PC.

  1. Fully quit and reopen WoW. A reload alone is not the activation step for this newly installed addon.
  2. At character selection, open AddOns and check that EUI Click Trace is enabled for your priest. Log in.
  3. Type /euict status. Expect ON, 0 observer errors, and 0 unavailable events. If it is OFF, type /euict on. If the command is unknown, recheck the addon and full restart.
  4. Click-cast a normal heal, then run /euict status again. The recent-event count should increase. Report nonzero error/unavailable-event counts before relying on the log.

Leave your tooltip and click-trigger settings unchanged for the first run.

B. Mark a problem as soon as it is safe

/euict mark tank stuck

Look for the confirmation: “Marked incident … Capturing 20 more seconds”. Then continue the recovery tests below.

A mark preserves up to 60 seconds before and 20 seconds after it. High event rates can shorten that window. The latest eight marked incidents are retained.

Optional one-key marker: open /macro, create a macro named Mark click issue, paste the command above, and put it on an action-bar slot with a spare keyboard binding. It only marks the log and does not cast a spell.

Avoid repeated marks within 20 seconds: a new mark ends the previous mark’s following window. Different notes, such as /euict mark buffs hidden, help identify later tests. Typing in chat itself can affect focus; note if marking appears to restore casting.

C. Recovery tests when the tank’s frame gets stuck

Stop as soon as it works and note the test number. Mark the failure first when safe. These tests are sequential; do not cast on another player until test 5.

1

Try an uncovered spot. Right-click another part of the same tank frame, away from defensive and debuff icons.

2

Leave and return. Move into empty screen space, return to the tank frame, and retry right-click Flash Heal.

3

Hover another player only. Move over another player’s frame without casting, return to the tank, and retry.

4

Cast normally on the tank. Select the tank as your target. With your cursor away from unit frames, cast Flash Heal from its normal action bar or keyboard binding, not a mouseover macro. Record whether it casts, then retry right-click on the tank frame.

5

Cast on another player. Click-cast Flash Heal on someone else, then return to the tank and retry.

For each failure, notice: any red error text; whether a cast bar starts; whether a spell-targeting cursor appears; and whether left-click also fails. Report the exact error if possible.

The marker’s following window is only 20 seconds. Do not rush these tests to fit it. If recovery takes longer, add a new labeled marker afterward, for example /euict mark recovered test 5, to preserve the recent events.

D. Optional settings tests between pulls

Change one thing at a time, out of combat. Do the recovery tests first. Record approximately how many pulls you tried; one successful cast does not rule out an intermittent problem.

6

Hide buff tooltips. In EllesmereUI’s Raid Frames settings, use the cog beside Show Raid Frames Tooltip and set Buff Tooltips → Hidden. Keep defensive icons enabled. Use Hidden, not Hidden In Combat. Check whether failures recur, especially while centre defensive icons are visible.

7

Hide debuff tooltips. Restore buff tooltips to their original setting first. Hide debuff tooltips, including the Dispellable tile’s separate tooltip override. Check whether the issue recurs. Hiding only the normal unit tooltip does not hide aura tooltips.

8

Cast on mouse release. Restore tooltip settings first. In Click Casting, turn Trigger Bindings on Down → off. Check whether casting on release prevents the problem.

Mark any failure with the test number, for example /euict mark test 6 failed. Restore your original settings when you finish.

E. Save the log and report back

  1. After the incident’s 20-second following window, finish the run and use /reload or log out normally. This writes the log to disk. A crash can lose unsaved events.
  2. Tell Codex the approximate time, spec, marker label, and what restored casting. The saved file can be inspected directly on this PC; no upload is needed.
  3. Use /euict off when you no longer want to collect events. Existing evidence stays available.
